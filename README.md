# fired-up-proposal

Website and local SEO proposal for Fired Up Fireplace & Stove Centre, prepared by SEO Kings.

A static page built from the Fired Up design system: its components (`fu/bundle.js`, `fu/bundle.css`), fonts, logo and photos. React 18 loads from cdnjs. No build step.

## Deploy

- **Netlify:** connect this repo; `netlify.toml` publishes the root and sends a `noindex` header.
- **Surge:** `npx surge . <name>.surge.sh`

The page is marked `noindex` so search engines don't list a client pitch. Photos are supplier shots from the design system; confirm usage rights before sharing publicly.
